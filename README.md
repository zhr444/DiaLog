**DiaLog** — это современное Full-Stack веб-приложение для удобного мониторинга уровня сахара в крови, учета потребляемых углеводов (ХЕ/граммы) и контроля питания. Проект спроектирован с упором на мобильный опыт (PWA) и безопасность данных пациентов.

---

## ✨ Ключевые возможности

- 📱 **Progressive Web App (PWA):** Возможность установки сайта на рабочий стол смартфона как нативного приложения (работает через Service Worker и Manifest).
- 🔒 **Безопасность:** Регистрация и авторизация пользователей с криптографическим хэшированием паролей (`Werkzeug.security`).
- 🌍 **Мультиязычность:** Встроенная поддержка 10 языков интерфейса (RU, EN, ZH, FR, ES, DE, UK, BE, KK, UZ) с сохранением выбора пользователя в `localStorage`.
- 🎨 **Кастомизация:** Поддержка светлой и темной тем оформления.
- 📊 **Аналитика:** Интерактивные графики динамики сахара (на базе `Chart.js`) и расчет средней статистики за выбранный период.
- 📄 **Экспорт отчетов:** 
  - Выгрузка данных в формате `.CSV`.
  - Генерация готовой к печати медицинской выписки в формате **PDF**.
- 👑 **Панель Администратора:** Скрытый дашборд для глобального мониторинга платформы (пользователи, логи, общая статистика).

## 🛠 Технологический стек

### Backend (Серверная часть)
* **Язык:** Python 3
* **Фреймворк:** Flask
* **База данных:** SQLite 3 (встроенная реляционная СУБД)
* **Архитектура:** REST API для взаимодействия с клиентом

### Frontend (Клиентская часть)
* **Разметка и стили:** HTML5, CSS3 (Адаптивная верстка, Flexbox/Grid)
* **Логика:** Vanilla JavaScript (ES6+)
* **Визуализация:** Chart.js

## 🗄 Архитектура Базы Данных (ER-модель)

Система использует реляционную структуру со связью `Один-ко-многим` (У одного пользователя может быть множество записей).

**1. Таблица `Users`**
- `UserID` (PK) — Уникальный ID.
- `Username` (Unique) — Логин пользователя.
- `PasswordHash` — Зашифрованный пароль.

**2. Таблица `BloodSugarLogs`**
- `LogID` (PK) — Уникальный ID записи.
- `UserID` (FK) — Ссылка на владельца записи.
- `RecordDate` — Дата и время.
- `SugarLevel` — Уровень сахара (ммоль/л).
- `MealContext` — Контекст (Натощак, Перед едой и т.д.).
- `BreadUnits` / `PortionGrams` — Хлебные единицы и граммы.
- `FoodName` / `Notes` — Название еды и комментарии.
